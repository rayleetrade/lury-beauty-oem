# Sample buying guide and inquiry improvements — 2026-09-23

## Purpose
Make sample selection and quoting concrete for a B2B buyer: show what can be observed, collect the actual brief, separate costs and explain the order schedule.

## Website changes
- Sample page: observed-specification table, four approval checks, three selectable request routes, itemised cost guide and five-stage timeline.
- Routes: photographed sample; compare style options; branded packaging sample. These are requests, not purchasable kits or stock reservations.
- The photographed tray visibly contains 48 clusters in six rows of eight; this is not a length, material, adhesive or wear-performance claim.
- Inquiry fields distinguish requested sample quantity from planned bulk quantity; add target arrival/launch timing and requested specification. Postcode is visible on the sample planner.
- Route changes retain entered contact and delivery details, update product interest and invalidate the previous prepared message.
- WhatsApp/email text carries the route, quantities, postcode, desired timing and specifications. The existing optional receiver normalises these fields from the shared field limits.
- Visible sample FAQ and JSON-LD contain the same answers. Sample metadata, product/OEM links and llms.txt point to the expanded information.
